# Riding Analysis

A Power BI dashboard analyzing ride data to uncover trends in ridership, revenue, and usage patterns.

## 📊 Overview

This project explores riding/trip data using **Microsoft Power BI** to visualize key metrics such as ride volume, revenue, peak hours, and rider behavior. The goal is to turn raw ride data into an interactive dashboard that supports data-driven decision-making.

## 📁 Contents

- `Riding Analysis.pbix` — Power BI project file containing the data model, DAX measures, and report visuals.

## 🔧 Tools & Technologies

- **Power BI Desktop** — data modeling, DAX calculations, and dashboard design
- **Power Query** — data cleaning and transformation

## 🚀 Getting Started

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only).
2. Clone or download this repository.
3. Open `Riding Analysis.pbix` in Power BI Desktop.
4. If the file is connected to a live data source, update the data source credentials/path and refresh the data.
